# 图片签章版 1（基于上游 1.15.7.5）

只在“批量打印（选图框块）”使用。支持 PDF、合并 PDF、PNG、JPG。通用矩形批打、单张打印、DWF 和 DWG 拆分不启用签章。原 DWG 不插入印章对象、不因签章保存更改。

## 加载

在中望 CAD 2026 中使用 NETLOAD 加载本签章版目录中的 BatchPlotter.dll。依赖 DLL 和 Plotters 目录应与主 DLL 一起保留。

若当前 CAD 已加载原版 BatchPlotter.dll，请先保存自己的工作并重新启动 CAD，然后加载签章版。已经加载的 .NET 插件无法在同一会话中可靠替换；不要重复加载两个版本。如设置过原版自动加载，请将其改为本签章版路径。

## 使用

1. 菜单“新增图框”，选择图框块。在“设置图框字段与纸张”窗口的“签章区域”一行点击“框选”，选择章应放置的两个对角点，保存模板。区域可清除，也可留空。
2. 已有模板可以从图框库中编辑，补选签章区域。保存后在批打窗口重新扫描，更新任务中的位置。
3. 打开“批量打印（选图框块）”（ZBP_SHOW_PANEL），扫描需要打印的图框。
4. 选择 PDF、PNG 或 JPG，选择签名/印章图片并启用“图片签章”。推荐使用透明 PNG，白色背景图片会覆盖背后的图线。
5. 点击该行“预览”可在 CAD 插件窗口查看带章的输出效果。点击开始打印；PDF 可同时选择合并。

图像按自身长宽比缩放并居中放在区域内，不拉伸。不同图框模板各自使用保存的位置；同一批使用所选的一张签章图片。图片位置和启用状态会记住；移动图片后需重新选择。

图框平移、缩放、旋转时签章位置随实例转换。可拉伸图框沿用上游模板右下角锚点。旧图框库继续可用；启用签章时，尚未配置区域的模板会提示补选，不会把无章输出当成签章完成。

## 验证范围

在独立中望机械版 2026 会话，以合成图框和 TEST STAMP 图片验证了：区域保存/回读/覆盖、库表格编辑保留区域、窗口控件、PDF/PNG/JPG、实际 PDF 合并、放大与留白、90/180/270 度旋转、未配置区域提示；原上游 16 项图幅/扫描测试通过。

旋转 PDF 的页面旋转标记曾导致章在页面外，已先用渲染测试复现失败，再修复并通过同一回归。最终测试将签章图片边界与 CAD 预设矩形的矢量边界比较，而不只是检查文件生成。

本轮没有操作用户当前业务图纸或使用真实印章。未验证 AutoCAD 宿主、物理出纸及所有动态块变体。
