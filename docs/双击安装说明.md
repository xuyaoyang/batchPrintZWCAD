# 双击安装

交付文件：项目 `release/LA批量打印-修订8-安装程序.exe`，单文件安装包，内含全部三个平台的插件及依赖。

1. 双击安装程序，勾选已识别的 CAD，点击“安装”。
2. 下次启动 CAD，通过“LA批量打印”菜单使用，无需每次 NETLOAD。

仅为当前 Windows 用户安装，不需要管理员权限。支持中望2026（含机械版）、AutoCAD2015–2027；未列出软件时请先启动该 CAD 一次，再重新运行安装程序。

文件写入 `%LOCALAPPDATA%/LA BatchPlot/20260922-R8-随机编号/`。每次安装使用独立目录，允许旧插件仍在 CAD 中运行。自动加载写入对应 CAD 的 HKCU Applications 下 `ZwcadBatchPlot` 或 `AcadBatchPlot`，不修改其他插件。正在打开的 CAD 保持当前版本，下次启动使用新路径。

如 CAD 自身弹出可信来源提示，应核对本安装目录后按其提示加载。安装器不修改 CAD 安全加载设置。取消自动加载可在插件菜单中选择“卸载自动加载”；此操作不删除安装文件。

插件功能实机验证环境：中望机械2026、AutoCAD2023。AutoCAD2025–2027仅编译及独立模块测试通过，未完成相应 CAD 实机验证；其他年份也没有逐年实测。

安装器测试：`安装程序.exe --self-test 绝对报告路径`，在随机临时注册表根和临时文件夹验证解压、平台识别、版本分流、自动加载值、重复注册，不改真实 CAD 注册项；`--list 绝对报告路径` 只导出本机识别结果。源码 `installer/Setup.cs`，构建入口为仓库内 `scripts/build-installer.ps1`。先构建三个插件版本，再打包。
