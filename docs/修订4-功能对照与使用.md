# 修订4：依据 MSteel 实际操作完善

2026-09-21 在用户打开的 AutoCAD2023 中实际操作 MSteel V2026.05.12，查看通用型批打、范围选择、自动扫描、比例/过滤、命名/排序及印章库；未发送实体打印任务、未保存原 DWG、未导出用户真实印章。依据观察独立实现，不修改 MSteel。

## 本轮变化

- 菜单按单张打印到文件、通用型、图框型的顺序排列；增加直接打开印章库的入口。仍使用 LA 名称及 ZBP 命令，可与 MSteel 并存。
- 图框型批打的“印章库…”可录入、改名、预览、启用/停用、移出及导入/导出图片章。导出文件 `.lastamps.json` 内含图片；移走原 PNG 后仍可使用。可以在库里选择一张启用的图片章，沿用图框内已录入的签章区域。原“选择图片…”入口保留。
- 通用型增加“命名、排序”：前缀、后缀、起始编号、编号位数、两种空间排序、实时文件名示例。前缀留空使用各自 DWG 名称。有识别图号/图名的清单沿用原字段命名设置，避免覆盖图号。
- 通用型增加“小图框过滤”：面积小于最大图框面积指定百分比时不进入打印清单；按每个 DWG、每个空间分别计算，避免大比例模型误过滤纸空间或其他文件。0 表示不过滤；恢复0可找回被过滤行，手动移出清单的行不自动恢复。
- 通用清单增加打印比例、图面尺寸、备注列。纸张候选及相邻 A 系列切换保持原有功能。

## 使用

双击项目 release 目录的 `LA批量打印-修订4-安装程序.exe`，选择 CAD 后安装。已打开的 CAD 需要下次启动才能换用新程序集，安装器不强制关闭 CAD。注册路径使用 `%LOCALAPPDATA%/LA BatchPlot/20260921-R4-*`。

菜单“LA批量打印 → 印章库管理”先录入透明 PNG。在“批打到文件(图框型)”中点击“印章库…”并选择图片。若该图框没有签章区域，先在图框信息库编辑并框选签章区域。签章仅用于此入口的 PDF/PNG/JPG，包括多页 PDF；不写入原 DWG。

## 与 MSteel 尚存的差异

| 项目 | 当前边界 |
|---|---|
| 入口顺序 | 当前仍先开清单，再点框选扫描；MSteel先选范围。 |
| 纸张与比例 | 当前候选仍组合选择，额外显示独立比例列；没有复刻每个单元格的相同交互。 |
| 默认比例提示 | 尚未加入MSteel的默认比例1:100过小时建议1:10提示。 |
| 命名/排序 | 当前支持两种空间顺序；没有完整复刻MSteel图示里的所有切换路径。 |
| 印章库格式 | LA的自包含JSON，不读取MSteel的专有.mslib2格式。需用原PNG重新录入。 |
| 印章属性 | 当前使用一张选中图片，按区域等比居中；未实现物理尺寸、多个章叠加、微小随机旋转及后置。没有加入授权码或期限流程。 |
| 签名库 | 可把图片签名当作图片章使用；未实现CAD闭合曲线签名库。 |
| 实体打印 | 尚未对齐MSteel新旧版批打到纸张流程，未实机出纸。 |
| 其他辅助工具 | 未逐项体验和复刻，不能声称全部一致。 |

修订4是已验证的功能增补版，不是MSteel所有功能或像素级界面的完整复制。

补充：用户已确认本次验收范围为文件批打、图框库、图片签章。最终过滤与属性命名交互测试先失败后修复，重跑通过，中望最终证据为 tests/evidence/stamp-20260921-164033；该修复为三平台共用源码，AutoCAD宿主记录为修复前同轮输出测试。
